# Tools and Libraries

| Tool/Library | Purpose | Project Link |
| :--- | :--- | :--- |
| **LangChain** | A foundational framework for developing applications powered by language models, providing the core abstractions for agents, chains, and tool integration. | [LangChain Documentation](https://python.langchain.com/) |
| **LangGraph** | An extension of LangChain designed for building stateful, multi-actor applications with cyclic computational graphs, crucial for implementing error-recovery loops. | [LangGraph Documentation](https://python.langchain.com/docs/langgraph) |
| **Microsoft AutoGen** | A programming framework enabling the development of LLM applications using multiple autonomous, conversing agents that can self-correct and collaboratively debug. | [AutoGen Project](https://microsoft.github.io/autogen/) |
| **CrewAI** | A framework for orchestrating role-playing AI agents, allowing researchers to observe how errors propagate when specific tasks are delegated across a multi-agent hierarchy. | [CrewAI Documentation](https://docs.crewai.com/) |
| **DSPy** | A framework for algorithmically optimizing LLM prompts and weights, providing robust pipelines that reduce hallucination and logic errors during complex multi-step reasoning. | [DSPy GitHub](https://github.com/stanfordnlp/dspy) |
