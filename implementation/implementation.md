# GitHub Implementations

| Repository | What it Implements | Why it is Relevant |
| :--- | :--- | :--- |
| **[microsoft/autogen](https://github.com/microsoft/autogen)** | The official source code for Microsoft's AutoGen framework, featuring multi-agent conversation patterns. | It provides raw, executable examples of how agents collaborate, pass context, and handle execution errors in real-time. |
| **[langchain-ai/langgraph](https://github.com/langchain-ai/langgraph)** | Source code for LangGraph, focusing on cyclic execution graphs for LLM agents. | Crucial for studying how developers build state machines that allow agents to pause, reflect, and recover from failures instead of crashing. |
| **[princeton-nlp/SWE-agent](https://github.com/princeton-nlp/SWE-agent)** | An autonomous AI agent designed to fix real-world software issues directly from GitHub repositories. | Demonstrates error propagation in practice by showing how agents interact with a terminal, interpret tracebacks, and attempt multi-step code repairs. |
| **[ysymyth/ReAct](https://github.com/ysymyth/ReAct)** | The official implementation of the ReAct (Reasoning and Acting) framework for language models. | Serves as the foundational baseline for evaluating how interleaving logical thoughts with API actions prevents cascading hallucinations. |
| **[Significant-Gravitas/AutoGPT](https://github.com/Significant-Gravitas/AutoGPT)** | An experimental open-source application showcasing the capabilities of the GPT-4 language model in autonomous continuous loops. | Acts as a primary case study for observing long-horizon error cascades, memory degradation, and infinite failure loops in agentic workflows. |
